# Etsy Fee & Profit Calculator

A lightweight Python utility designed to calculate standard Etsy seller fees, overhead costs, and net profit margins.

## Features
- **Listing Fee:** $0.20 per item
- **Transaction Fee:** 6.5% on total revenue (item price + shipping)
- **Payment Processing:** 3% + $0.25 standard US rate
- **Offsite Ads:** Configurable 15% calculation
- **Net Margin:** Instant calculation of pure profit and percentage margin
